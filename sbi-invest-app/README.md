# 投資成績 Android v2.0.0

SBI証券のCSVを端末内だけで集計・分析する個人用Androidアプリです。

## 主な機能
- 実現損益 / 配当金・分配金 / 約定履歴 CSVの複数読込・重複除外
- 月別・年別の売買益、配当、優待価値、総合損益
- 年間配当目標メーター（初期値100万円、変更可）
- 配当 + 優待価値のインカム収益
- 前年対比
- 銘柄別の完全成績表と銘柄詳細
- ベスト / ワースト銘柄 TOP10
- 勝率、平均損益、PF、最大利益/損失、最大連勝/連敗
- 現物 / 信用、信用買い / 信用売り、NISA / 特定 / 一般の別成績
- 信用コストと、CSVに列がある場合の日歩・逆日歩・貸株料・HYPER料内訳
- 約定履歴からFIFO推計した平均保有期間、銘柄ごとの保有→売却サイクル
- 曜日別成績、月間勝敗カレンダー
- 株主優待の券面価値 / 自分価値 / 売却換算価値
- 優待クロスの手数料 / 貸株料 / 逆日歩 / その他費用と実質お得額
- 優待ランキング、年間優待獲得額
- 確定申告用の参考集計（正式書類の代替ではありません）
- バックアップ / 復元、各種CSV書き出し
- ダークモード
- データは外部送信せず端末内保存

## 集計上の考え方
総合損益は「SBI実現損益 + 配当（税引後） + 優待の選択評価価値 + その他収支」です。
SBI実現損益に手数料等が反映されている場合の二重控除を避けるため、信用コストや優待クロスの取得コストは分析画面・優待画面で別表示します。優待クロスの「実質お得額」は優待評価価値から手入力した取得コストを引いて計算します。
