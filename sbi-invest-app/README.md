# 投資成績 Android v3.0.0

SBI証券のCSVを端末内だけで集計・分析する個人用Androidアプリです。

## v3で追加・修正
- 同日・同額の正当な複数取引を保持しつつ、同じCSVの再読込だけ重複除外する方式へ修正
- CSVごとに「取込取消」が可能（v3で読み込んだデータ）
- 不正日付（例: 2/30）を除外
- 優待CSVの重複除外
- 優待履歴の編集
- 銘柄画面に独立した年フィルター
- 月別・年別を同じCSVへ正しく書き出すよう修正
- 勝率を「銘柄×日単位 / CSV明細単位」で選択可能
- 最大ドローダウン、プラス月率
- 累計損益チャート
- 配当ランキング、上位5銘柄集中度
- 優待クロス効率（実質お得額 ÷ コスト）と1件平均
- 優待クロス費用を総合損益から控除するか選択可能
- 推計保有ポジション（現物 / 信用買い / 信用売り）を銘柄詳細に表示
- データ診断
- 端末内セルフチェック

## 既存の主な機能
- 実現損益 / 配当金・分配金 / 約定履歴 CSVの複数読込
- 月別・年別の売買益、配当、優待価値、総合損益
- 年間配当目標メーター（初期値100万円、変更可）
- 配当 + 優待価値のインカム収益
- 前年対比
- 銘柄別の完全成績表と銘柄詳細
- ベスト / ワースト銘柄 TOP10
- 勝率、平均損益、PF、最大利益/損失、最大連勝/連敗
- 現物 / 信用、信用買い / 信用売り、NISA / 特定 / 一般の別成績
- 信用コストと、CSVに列がある場合の日歩・逆日歩・貸株料・HYPER料内訳
- 約定履歴からFIFO推計した平均保有期間、銘柄ごとの保有→売却サイクル
- 曜日別成績、月間勝敗カレンダー
- 株主優待の券面価値 / 自分価値 / 売却換算価値
- 優待クロスの手数料 / 貸株料 / 逆日歩 / その他費用と実質お得額
- 優待ランキング、年間優待獲得額
- 確定申告用の参考集計
- バックアップ / 復元、各種CSV書き出し
- ダークモード
- データは外部送信せず端末内保存
